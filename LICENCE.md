## 🧩 About

**Path of Titans Overlay** is a curated list of Path of Titans open-source tools:

- **Overlays** — on-screen helpers, layout notes, entity tracker, coordinate display
- **Quality-of-Life Helpers** — growth planner, diet tracker, map notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Entity Tracker — display nearby creatures and resources
- Coordinate Display — show current position and map grid
- Growth Planner — track growth stages and dietary needs
- Stamina Meter — visual stamina and hunger indicators

### Wallhack
- Skin Catalog — browse dinosaur skins and color patterns
- Custom Skin Notes — organize appearance preferences
- Map Overlay — display map markers and points of interest

### Aimbot
- Route Planner — plan migration and quest routes
- Waypoint Notes — mark important locations
- Server Info — display server name and player count
